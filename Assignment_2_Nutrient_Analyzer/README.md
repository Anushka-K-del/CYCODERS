# 🥗 Nutrient Analyzer

## 📌 About the Project

Nutrient Analyzer is a simple web-based project that helps users check the nutritional information of different food items.

The user enters the name of a food and its quantity in grams. The application then searches for the food and displays its nutrition information.

## ✨ Features

- 🔎 Search for food items
- ⚖️ Enter quantity in grams
- 🔥 Calculate calories
- 💪 Display protein content
- 🍞 Display carbohydrates
- 🥑 Display fat content
- 🌾 Display fiber content
- ❌ Shows a message if the food is not found

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- USDA FoodData Central API
